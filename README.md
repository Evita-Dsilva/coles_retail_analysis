# Coles Retail Analysis

End-to-end retail sales analytics project using **MySQL, Power BI, and Excel**. This project demonstrates data cleaning, SQL querying, KPI creation, and interactive dashboard development using an Australian retail sales dataset.

## Project Overview

The goal was to analyse retail performance across stores, identify sales trends, measure profitability, and build dashboards that support business decision-making.

## Tools & Skills

* **SQL (MySQL)**
* **Power BI**
* **Microsoft Excel**
* Data Cleaning
* Data Analysis
* DAX Measures
* Dashboard Design

## Business Questions Answered

* What is the total revenue and profit?
* Which states and stores perform best?
* How does monthly revenue change over time?
* What is the overall profit margin?
* Which stores are meeting forecast targets?
